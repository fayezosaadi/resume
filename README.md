# Resume

Personal resume built with [Typst](https://typst.app/), a modern markup-based typesetting system.

## Features

- Clean, professional design with custom styling
- Responsive typography and spacing optimized for readability
- Brand-consistent color scheme and section headers
- Single command compilation to PDF

## Compile

```bash
npx typst compile resume.typ fayez-saadi-resume.pdf
```

## Requirements

- Node.js (for Typst CLI via `npx`)

## Structure

- `resume.typ` — Main resume document with custom macros for consistent formatting
- `fayez-saadi-resume.pdf` — Compiled PDF output

## Font

Uses [Inter](https://rsms.me/inter/), an optimized sans-serif typeface designed for computer screens.
